# tmux Configuration with Mouse Interactivity

This repository contains a tmux configuration file that enables mouse interactivity. With this configuration, you can:

- Navigate through the terminal using the mouse.
- Resize tmux splits via the mouse.

## Setup

To set up the tmux configuration, follow these steps:

1. Clone the repository:

   ```bash
   git clone https://github.com/p3p3t0/tmux_conf.git
```
2. Copy the tmux.conf file to your home directory:
```bash
cp tmux.conf ~/.tmux.conf
```
3. Start tmux with the new configuration:
```bash
tmux -f ~/.tmux.conf
```
That's it! Enjoy your tmux with mouse interactivity!
